BACKEND API (FastAPI - Port 8001)
----------------------------------

URL: http://localhost:8001/docs
Purpose: Interactive API testing and documentation
Features:
    - Try out endpoints
    - See request/response format
    - Check error codes
    - Auto-generated documentation

Available Endpoints:
    1. GET /health
       - Purpose: Check if server is running
       - URL: http://localhost:8001/health
       
    2. GET /task/?focus_area=calibration
       - Purpose: Get a single task
       - Focus areas: calibration, error_detect, correction, certainty
       - Example: http://localhost:8001/task/?focus_area=calibration
       
    3. GET /task/batch?focus_area=calibration&limit=5
       - Purpose: Get multiple tasks
       - Parameters: focus_area, limit (default 5)
       - Example: http://localhost:8001/task/batch?focus_area=error_detect&limit=10
       
    4. POST /response/
       - Purpose: Submit model responses for evaluation
       - Body: {"session_id": "xxx", "response": {...}}
       - Use /docs interface to try this

================================================================================
                      4. DASHBOARD GUIDE
================================================================================

STEP-BY-STEP: Using the Streamlit Dashboard

1. Open Browser
   - Navigate to: http://localhost:8501
   - Wait for page to load (first load may take 10-15 seconds)

2. Dashboard Layout
   You'll see:
   
   LEFT PANEL (Sidebar):
   ├─ Configuration settings
   ├─ Focus area selection
   └─ Evaluation filters
   
   MAIN PANEL:
   ├─ MetaCog Index Gauge (top left)
   ├─ Overall Metrics (top right)
   ├─ Calibration Curve (bottom)
   ├─ Focus Breakdown (right)
   └─ Live Task Feed (scrollable)

3. Selecting Focus Area
   - On the left sidebar, find "Focus Area"
   - Click dropdown menu
   - Select from:
     * Calibration - Tests model confidence accuracy
     * Error Detection - Tests error identification
     * Correction - Tests error fixing ability
     * Certainty - Tests confidence estimation
   - Dashboard updates automatically

4. Understanding MetaCog Index
   - Top-center gauge shows overall score 0-100
   - Green zone (75-100): Excellent metacognition
   - Yellow zone (50-74): Good metacognition
   - Red zone (0-49): Needs improvement

5. Calibration Curve
   - Shows relationship between confidence and accuracy
   - Diagonal line = Perfect calibration
   - Above diagonal = Under-confident (good)
   - Below diagonal = Over-confident (risky)

6. Focus Breakdown
   - Pie chart showing score distribution
   - Each slice = one focus area
   - Hover to see exact percentages

7. Live Task Feed
   - Scrollable list of recent evaluations
   - Shows task, prediction, confidence
   - Color-coded based on accuracy

8. Refresh Data
   - Dashboard auto-refreshes every 5 seconds
   - Manual refresh: F5 or Cmd+R

================================================================================
                         5. API USAGE
================================================================================

Getting a Task via API
-----------------------

Method: GET
Endpoint: /task/
Parameters:
    - focus_area (required): calibration, error_detect, correction, certainty
    - limit (optional): number of tasks to return

Example Request:
    http://localhost:8001/task/?focus_area=calibration

Example Response:
    {
      "task_id": "calib_001",
      "focus_area": "calib",
      "prompt": "Who wrote '1984'?",
      "ground_truth": "George Orwell",
      "metadata": {
        "difficulty": "easy",
        "contested": false
      }
    }


Submitting a Response via API
-------------------------------

Method: POST
Endpoint: /response/
Content-Type: application/json

Request Body:
    {
      "session_id": "session_123",
      "response": {
        "task_id": "calib_001",
        "raw_text": "George Orwell",
        "metadata": {}
      },
      "timestamp": 1711779600.123
    }

Example Response:
    {
      "status": "success",
      "message": "Response collected and evaluated.",
      "evaluation_result": {
        "task_id": "calib_001",
        "parsed_response": {...},
        "focus_scores": [...],
        "anomaly_report": null
      }
    }

Testing via Dashboard

2. Find the endpoint you want to test
3. Click "Try it out"
4. Enter parameters
5. Click "Execute"

================================================================================
                      6. TROUBLESHOOTING
================================================================================

Problem: "Address already in use" Error
Solution:
    1. Check if another instance is running on that port
    2. Stop other processes: taskkill /F /IM python.exe
    3. Try different port: Add --port 8002 to command
    4. Restart: Close all CMD windows and start fresh

Problem: "ModuleNotFoundError" Error
Solution:
    1. Activate virtual environment:
       .venv\Scripts\activate.bat
    2. Reinstall dependencies:
       pip install -r requirements.txt
    3. Verify Python version (should be 3.11+):
       python --version

Problem: Dashboard not loading
Solution:
    1. Make sure backend is running (should have "startup complete")
    2. Wait 10-15 seconds for first load
    3. Check browser console (F12) for errors
    4. Clear browser cache: Ctrl+Shift+Delete
    5. Try incognito/private mode

Problem: 404 errors when accessing dashboard
Solution:
    1. Make sure you're accessing the right port
    2. Frontend = 8501 (Streamlit)
    3. Backend = 8001 (FastAPI)
    4. Don't mix up the addresses

Problem: Slow performance
Solution:
    1. Close other applications
    2. Check available RAM: tasklist
    3. Reduce task batch size in API calls
    4. Restart both services

================================================================================
                    7. STOPPING THE SERVICES
================================================================================

Method 1: Normal Stop
-------
In each Command Prompt window where services are running:
    Press: CTRL + C
    
Wait for graceful shutdown message.

Method 2: Force Stop (if Method 1 doesn't work)
-------
Open new Command Prompt:
    taskkill /F /IM python.exe

This will terminate all Python processes.

Method 3: Stop Individual Services
-------
Windows Task Manager:
    1. Press: Ctrl + Shift + Esc
    2. Find "python.exe" entries
    3. Right-click and select "End Task"
